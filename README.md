# Smart Banking System

Beginner-friendly Python project using only the Python standard library.

## Run

Open the project folder in VS Code and run:

    python main.py

## Files

- main.py - starts the program
- account.py - stores account data
- account_manager.py - account creation and login
- banking.py - banking operations and menu
- transactions.py - transaction history and receipts
- rewards.py - reward points
- calculator.py - interest calculator

## Features

- Account creation
- Automatic account number
- Password login
- Three login attempts
- Balance checking
- Deposit
- Withdrawal
- Transfer
- Transaction history
- Date and time
- Reward points
- Silver/Gold status
- Interest calculator
- Low-balance warning
- Mini receipt

## Note

This is a college learning project. Data is stored only in Python memory and is reset when the program closes.
